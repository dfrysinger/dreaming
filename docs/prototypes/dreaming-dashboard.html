Skill text

Copilot CLI plugins

Install, troubleshoot, and reason about GitHub Copilot CLI extensibility, including plugins, marketplaces, and MCP servers.

When to use

Use when a plugin install fails, an MCP server will not start, or someone asks whether an extension from another agent works in Copilot CLI.

Procedure

Identify the extension type, inspect the authoritative Copilot CLI configuration, reproduce the failure at the native boundary, and distinguish portable MCP protocol behavior from agent-specific packaging.
